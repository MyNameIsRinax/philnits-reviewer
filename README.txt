IT PASSPORT (ITPEC IP) EXAM REVIEWER
====================================

How to use
  1. Unzip this folder.
  2. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).
     No internet or installation needed. Keep the img folder next to index.html.

Exams included (100 questions each)
  October 2024, April 2024, October 2023, April 2023, October 2022, April 2022

Features
  - Pick any single exam, or use "Random mix" to draw from the exams/years you choose
    (with a question count of 10, 25, 50, 100 or All).
  - "Shuffle answer choices" randomizes the order of A-D (the letters are reassigned).
    Untick it to see the original order.
  - After answering, every choice shows an explanation of why it is correct or not correct.
  - Progress is saved in your browser. Use "Clear all progress" to start over.
  - Results screen lists missed questions and lets you retry only those.
  - Keyboard: A-D to answer, Right arrow/Enter for next, Left arrow for previous.

Files
  index.html, style.css, app.js  - the site
  data.js                        - answers and explanations
  img/                           - question and choice images, one folder per exam

You can also upload the whole folder to any static host (GitHub Pages, Netlify, etc.).
